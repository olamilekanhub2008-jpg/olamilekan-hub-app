# Olamilekan Hub — Mobile App Starter

This is Version 1 of the Olamilekan Hub cross-platform app.

## Included
- Home
- Services
- Order Service form
- WhatsApp order button
- Portfolio placeholders
- Contact page
- About page
- iOS and Android package identifiers

## Important
1. In `App.js`, replace `2340000000000` with your real WhatsApp number in international format, without `+` or spaces.
2. Add your logo and portfolio images later.
3. Payment, customer accounts, file uploads, push notifications and an admin dashboard are not connected yet; these are the next development stage.

## Run
Install Node.js and Expo tooling on a computer, then:
npm install
npx expo start

For a production build, use an Expo/EAS build workflow and then submit the resulting iOS build to App Store Connect and Android build to Google Play Console.
